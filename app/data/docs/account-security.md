# Account Security

NimbusNotes supports two-factor authentication (2FA) using an authenticator app. SMS codes are not supported.

To turn on 2FA, open Settings, choose Security, and select Enable two-factor authentication. You will receive 10 one-time recovery codes; store them somewhere safe.

If you lose access to your authenticator app, sign in with a recovery code. Each recovery code works only once.

Password reset links expire after 1 hour. After 5 failed sign-in attempts, the account is locked for 15 minutes.

NimbusNotes support will never ask for your password or your 2FA codes.
