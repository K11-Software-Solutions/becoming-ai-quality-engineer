## What grading buys

| | Graded (0-3) | Pass/fail |
|---|---|---|
| Mean information per rating | 0.290 | 0.054 |
| Overall severity z (lean / SE) | -7.6 | -5.8 |
| Ratings to detect a 0.3-logit lean (5%, 80% power) | 601 | 3203 |

Information is in each model's own logit units, so the ratings-needed row is a planning guide, not an exact exchange rate. The z row is the like-for-like comparison on these ratings: a larger |z| means the same data give a clearer verdict.

Grading only helps if reviewers can use the scale consistently: check reviewer-to-reviewer weighted kappa (`python -m evals.judge.judge_agreement`) before trusting the extra information.
