# Grader severity report (sample)

Generated by `python -m evals.severity.run_severity` on top of commit `d710e69`, with SIMULATED reviewers. It illustrates the method; it is not evidence about human reviewers.


Mode: **SIMULATED reviewers with known severities (teaching mode, not human data)**
Data: `items.jsonl@1a3ee3d98c60`
